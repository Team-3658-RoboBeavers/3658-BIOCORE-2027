# Runtime Choreo exports

Place reviewed, solved Choreo Swerve .traj files here. They deploy to
/home/systemcore/deploy/choreo. Registration is explicit in ChoreoAutos.

SimulationStraight.traj is a hand-authored analytic simulation/test fixture: 0.25 m over
2 s, no field assumptions, no mechanisms, no optimizer-derived forces. It is only offered by
the simulation chooser and cannot run on real hardware through that option.

See [Choreo Autonomous](../../../../docs/Choreo-Autonomous.md) for export/registration and gates.
